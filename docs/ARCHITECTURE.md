# 架构基线

本文只记录尚待分阶段验证的架构方向，不承诺未实现的技术细节。具体框架、依赖和版本由后续外部审阅决定；Phase 0 不提前选定。

## 基础方向

```text
用户本人登录 BOSS
        ↓
Chrome / Edge MV3 浏览器扩展
        ↓
读取当前页面已经展示的 DOM
        ↓
后续接入只绑定 127.0.0.1 的本地服务
        ↓
本地 SQLite
        ↓
规则分析 + 结构化 LLM 分析
        ↓
本地审核界面
```

以上是阶段方向，不表示任一组件已经实现，也不表示真实 BOSS 页面 DOM 结构已经得到验证。

## 分阶段约束

第一阶段先验证 Chrome / Edge MV3 浏览器扩展的被动采集能力：扩展只读取用户本人正在浏览的页面中已经展示的 DOM 内容。真实页面上的字段、结构、稳定性和可得性必须通过后续人工验证确认，不得把未验证的 DOM 假设写成事实。

在采集能力通过真实验证之前：

- 不开发后端、本地服务、数据库或 AI 分析；
- 不提前建设复杂的数据管线；
- 不选定未经外部批准的具体框架、依赖或版本。

采集能力通过外部审阅和真实人工验证后，后续本地服务只能绑定 `127.0.0.1`，不得暴露到局域网或公网。SQLite、规则分析、结构化 LLM 分析和本地审核界面均由各自未来阶段另行设计、实施和验收。

## 安全与行为边界

- 只读取用户当前页面已经展示的 DOM 内容。
- 不直接访问、调用或逆向 BOSS 私有 API。
- 不复制 Cookie，不导出 Session，不请求密码或验证码。
- 不后台无人值守浏览或抓取。
- 不自动翻页，不自动批量点击岗位。
- 不自动投递，不自动打招呼，不自动聊天。
- 不绕过验证码、伪装浏览器指纹或实现反风控能力。

## Phase 0 状态

本阶段只建立文档、目录结构、治理基线和长期仓库记忆。浏览器扩展、本地服务、SQLite、分析能力和审核界面均未开发。

## Phase 1 已批准工具链

外部网页版 ChatGPT 已为 Phase 1 的浏览器扩展基线批准以下工具链：

- Vanilla TypeScript
- npm
- WXT 0.21.4
- Vite 8.x
- Vitest
- ESLint 10.x
- Chrome / Edge Manifest V3

工具链批准不改变本文既有安全边界。各批次仍只能实现外部 Prompt 明确允许的范围。

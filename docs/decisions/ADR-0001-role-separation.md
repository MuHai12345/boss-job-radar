# ADR-0001：外部总控与实现角色分离

- 状态：项目治理基线
- 日期：2026-09-01

## 背景

项目需要让产品方向、架构决策和验收结论保持稳定，同时允许 Codex 在明确范围内执行代码和文档任务。聊天上下文可能变化，因此需要可追溯的长期共享记忆。

## 决策

- 外部网页版 ChatGPT 负责产品目标、架构决策、任务拆解、GitHub 审阅、验收和是否进入下一阶段的决定。
- Codex 只负责当前任务的实现、适用测试、提交和事实性工作日志。
- GitHub 仓库作为两个角色之间的长期共享上下文；真实文件、commit 和验证记录优先于临时聊天记忆。
- Codex 的构建、Lint 和测试结果只属于实现证据，不等于外部验收。

## 结果

Codex 不得自行改变重大方向、宣布验收通过或开始下一批。每轮结束后应提交清晰的真实改动并等待外部审阅。

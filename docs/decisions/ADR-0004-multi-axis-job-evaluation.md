# ADR-0004：采用多轴岗位评价

- 状态：领域模型基线
- 日期：2026-09-01

## 背景

单一总分会混合岗位内容、用户入门条件、招聘时效和用户个人操作状态，难以解释低分原因，也容易让仍有价值的岗位被静默隐藏。

## 决策

分别保存和展示：

- 岗位性质；
- 入门可行性；
- 经验门槛；
- 岗位状态；
- 用户审核状态；
- 岗位适合度；
- 当前机会优先级。

“岗位本身是否值得作为转行入口”与“岗位当前是否值得优先查看”是两个不同问题。岗位适合度侧重职责、入门条件和成长价值；当前机会优先级还会考虑招聘者活跃、发布时间、链接可用性和信息完整性等时效信号。

例如，一个岗位可以具有较高的岗位适合度，但由于招聘者长期不活跃或链接状态异常，当前机会优先级较低。它仍然必须保留并显示原因，不得消失。

## 结果

后续规则和界面必须保留各轴原始结论、未知状态和解释依据。排序、降级或风险标记不能转化为静默删除，最终查看与投递选择由用户本人完成。

# ADR-0003：禁止私有 API、自动交互和凭证收集

- 状态：不可绕过的产品与安全边界
- 日期：2026-09-01

## 背景

项目只为用户本人正常求职提供辅助，不代替用户与平台或招聘者互动。私有接口、自动交互、凭证收集和规避平台安全机制均超出项目目标，并带来隐私、安全和平台合规风险。

## 决策

项目明确禁止：

- 使用、调用或逆向 BOSS 私有 API；
- 自动投递；
- 自动聊天；
- 自动打招呼；
- 验证码绕过；
- 浏览器指纹伪装；
- 反风控实现；
- 获取、请求、保存或导出 Cookie、Session、密码和验证码；
- 后台无人值守浏览、自动翻页或自动批量点击岗位。

## 结果

系统只处理用户当前页面已展示且任务允许读取的内容，向用户提供记录和分析辅助。任何查看、沟通和投递决定及动作均由用户本人完成。未来任务不得以技术便利为理由弱化此边界。

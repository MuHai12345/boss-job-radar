# ADR-0002：浏览器扩展优先

- 状态：架构方向基线，待分阶段验证
- 日期：2026-09-01

## 背景

本项目是用户本人的求职辅助工具。当前尚未验证真实 BOSS 页面 DOM 的结构、字段可得性和稳定性，直接建设独立爬虫或复杂后端会在核心采集假设未知时扩大成本和风险。

## 决策

优先采用 Chrome / Edge MV3 浏览器扩展：

- 用户本人正常登录并浏览 BOSS；
- 扩展只读取用户当前页面已经展示的 DOM 内容；
- 这种被动读取方式更符合个人辅助工具和用户主动浏览的边界；
- 第一阶段使用脱敏 fixture 建立解析基础，随后由用户人工验证真实页面 DOM 是否能可靠取得目标字段；
- 在采集能力尚未通过真实验证和外部审阅前，不提前建设复杂后端、数据库或 AI 能力。

## 未决与约束

本 ADR 不把任何尚未验证的 DOM 结构或字段选择器写成确定事实。真实页面验证失败时，应记录事实并交由外部项目总控决定后续路线，而不是擅自扩大采集手段。
